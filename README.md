# 基于 C++ 的在线判题系统（Online Judge）

《软件工程实验》课程设计项目。

## 项目简介
面向编程教学与自主训练场景的在线判题系统，提供题目管理、代码在线提交、自动编译运行与判定、判题结果反馈、排行榜等功能，采用 B/S 架构，支持 C++ 单语言判题。

## 技术栈
- **语言**：C++（C++17）
- **环境**：Windows 11 + WSL2（Ubuntu 24.04），g++ 13.3.0
- **构建**：CMake 3.28.3 / Make 4.3
- **服务端**：epoll + HTTP、线程池、异步判题队列
- **存储**：MySQL、Redis（排行榜）
