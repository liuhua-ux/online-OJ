关于

一个从零手写的 OJ（在线判题）系统。

一期用 Flask 把整条链路跑通：判题器 → 队列 → 落库 → 登录 → 题库 → 排行榜。二期把 Web 层换成 C++ 自研服务端 —— 功能不变，只换实现。

二期已经做到的

  • socket → bind → listen → accept 的完整生命周期
  • 自己解析请求行 / 头部 / body，处理半包与粘包
  • 静态文件服务 + 按后缀推 Content-Type
  • 目录穿越防御（realpath 规范化 + 前缀校验）
  • POST 表单解析 → 回显页，并做 HTML 转义防 XSS
  • epoll + 线程池，把「等」和「干」拆开
  • 从 MySQL 读取题库，渲染题目详情页

这一页本身就躺在磁盘上：www/about.html。
