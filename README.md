# 基于 C++ 的在线判题系统（Online Judge）

《软件工程实验》课程设计项目。

## 项目简介
面向编程教学与自主训练场景的在线判题系统，提供题目管理、代码在线提交、自动编译运行与判定、判题结果反馈、排行榜等功能，采用 B/S 架构，支持 C++ 单语言判题。

## 技术栈
- **判题层**：C++17（g++ 13.3.0），独立可执行程序，通过命令行参数 + 退出码对外交互
- **Web 层**：一期 Python 3.12 + Flask 3.1.3；二期计划替换为 C++ socket + epoll + 线程池自研服务端（判题层接口不变，替换不影响判题）
- **开发环境**：腾讯云 VPS（Ubuntu 24.04）+ VS Code Remote-SSH
- **构建**：g++ 直接编译（CMake 3.28.3 / Make 4.3 备用）
- **存储**（规划中）：MySQL、Redis（排行榜）

## 目录结构
```
hello_world/   实验1：Hello World 程序（工具链验证）
judge_demo/    判题核心：编译、运行、判定
  judge.cpp      判题主程序
  NOTES.md       设计与进展笔记
web/           Web 层（一期）：Flask 应用，调用判题器并展示结果
  app.py          Flask 应用：/submit 路由调用判题器并返回结果
  try_judge.py    试手脚本：验证判题器能否被 Python 调起
```
